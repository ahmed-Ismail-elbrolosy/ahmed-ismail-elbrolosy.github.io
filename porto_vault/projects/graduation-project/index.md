# Graduation Project: Autonomous Lifting AGV

## Site status

Dedicated project page

## Summary

Autonomous mecanum-wheel AGV for lifting and relocating warehouse racks.

## Date

2026 to present

## Status

Ongoing

## Technologies

ROS2, mecanum drive, embedded systems, autonomous navigation, SolidWorks

## Overview

The user selects a warehouse rack, then the AGV plans a path, positions itself underneath, lifts the rack, and transports it without manual driving.
